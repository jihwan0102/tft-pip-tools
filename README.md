# tft-pip-tools

아이폰에서 **TFT(전략적 팀 전투)를 하면서 덱 가이드를 PiP(화면 속 화면)로 띄워 두는** 웹 도구예요.
설치할 것 없이 사파리에서 페이지를 열고 버튼 한 번이면 됩니다.

| 페이지 | 주소 | 하는 일 |
|---|---|---|
| **TFT 덱 PiP** | https://jihwan0102.github.io/tft-pip-tools/comps.html | MetaTFT 추천 덱을 한 장씩 PiP로 보여줘요 |
| PiP 시계 / 타이머 | https://jihwan0102.github.io/tft-pip-tools/ | 시계나 카운트다운을 PiP로 띄워요 |

## TFT 덱 PiP 사용법

1. 아이폰 **사파리**로 [comps.html](https://jihwan0102.github.io/tft-pip-tools/comps.html)을 엽니다.
2. 덱 목록이 뜨고, 아래 로그에 `영상 모드: PiP ±10초 버튼으로 덱 이동`이 나올 때까지 몇 초 기다립니다.
3. 보고 싶은 덱을 목록에서 누르거나 **◀ ▶** 로 고릅니다.
4. **PiP 시작**을 누르면 덱 화면이 작은 창으로 떠요.
5. 홈으로 나가서 TFT를 켜면 PiP 창이 게임 위에 그대로 남아 있어요.

### PiP 창에서 덱 넘기기
- PiP 창의 **⏪ 10초 / ⏩ 10초** 버튼 = **이전 덱 / 다음 덱**이에요.
- 페이지의 **자동 넘김**(10·20·40초)을 켜 두면 알아서 다음 덱으로 넘어가요.
- 창 크기는 핀치로 키우고 줄일 수 있고, 옆으로 밀면 잠깐 숨겨져요.

### 화면에 나오는 정보
- **티어(S~D)·순위·덱 이름**, 평균 등수, 운영 방식(예: `7레벨 리롤`, `빠른 9`)
- **최종 배치 유닛** — 테두리 색이 코스트(회색 1 → 금색 5), 위에 **★★★**가 있으면 3성 목표
- **핵심 캐리 3명과 아이템 3개**
- 활성화되는 **시너지**

### 데이터
- [MetaTFT](https://www.metatft.com/comps)의 **현재 패치 · 최근 3일 · 플래티넘 이상** 통계를 써서, 사이트 기본 화면과 같은 순서·티어로 보여줘요.
- 페이지를 열 때마다 새로 받아오고, 열어 둔 채로 하루가 지나면 PiP가 꺼져 있을 때 자동으로 새로고침해요.

## PiP 시계 / 타이머 사용법

1. [index.html](https://jihwan0102.github.io/tft-pip-tools/)을 열고 **PiP 시작**을 누르면 시계가 떠요.
2. **모드** 버튼을 누르고 분을 입력하면 카운트다운으로 바뀌어요. 0이 되면 화면이 빨개져요.
3. 주소 뒤에 `?t=분`을 붙이면 바로 타이머로 시작해요. 예: `…/tft-pip-tools/?t=5`

## 동작 환경

- **iOS / iPadOS 사파리** 기준으로 만들었어요 (최신 버전 권장).
- 덱 화면은 브라우저 안에서 **MP4 영상으로 만들어(WebCodecs)** PiP로 띄워요. 영상을 만들 수 없는 브라우저에서는 실시간 스트림으로 대신 보여주는데, 이때는 PiP의 ±10초 덱 넘기기가 안 돼요.
- 아무 데이터도 서버로 보내지 않아요. 모든 처리는 내 폰 안에서 끝나요.

## 문제 해결

| 증상 | 해결 |
|---|---|
| PiP 시작을 눌러도 안 뜸 | 페이지를 한 번 새로고침하고, 로딩이 끝난 뒤 다시 눌러 주세요. 저전력 모드에서는 PiP가 막힐 수 있어요 |
| ±10초를 눌러도 덱이 안 바뀜 | 로그에 `영상 생성 실패`가 있으면 스트림 모드예요. 페이지의 ◀ ▶ 를 써 주세요 |
| 아이콘 대신 글자만 보임 | MetaTFT 이미지 서버를 못 불러온 경우예요. 새로고침해 보세요 |
| `불러오기 실패` | MetaTFT API가 일시적으로 응답하지 않는 경우예요. 잠시 뒤 다시 열어 주세요 |

---

MetaTFT 및 Riot Games와 관계없는 개인 프로젝트예요. 덱 데이터와 아이콘의 권리는 각 소유자에게 있습니다.
